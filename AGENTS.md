# AGENTS.md

## Agent skills

### Issue tracker

Issues live in GitHub Issues, managed with the `gh` CLI. See `.agents/docs/issue-tracker.md`.

### Triage labels

Five canonical triage labels used verbatim: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `.agents/docs/triage-labels.md`.

### Domain docs

Single-context, under `.agents/docs/`: `CONTEXT.md` and `adr/` live there rather than at the repo root; research references live in `.agents/research/`. See `.agents/docs/domain.md`.
