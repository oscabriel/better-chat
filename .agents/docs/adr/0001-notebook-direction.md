# Product direction: agent notebook

Better Chat is rebuilt as a notebook for individual thought work: the user captures an unfinished thought, an agent helps shape it, and the document, not the conversation, is the main result. This supersedes the earlier delegated-work management-inbox direction in `plans/reimagining-better-chat-2026.md` and drops the earlier plans for concurrent agent editing, a local IndexedDB database, and a separate Notebook Agent. The existing chat app is a source of reusable code after dependency review, not a constraint.
