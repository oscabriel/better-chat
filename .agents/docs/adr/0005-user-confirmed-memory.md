# Memory is user-confirmed only

Cross-note preferences are created only by explicit user action ("remember this" or accepting an inline offer in chat). Each preference has a scope and a link to the confirming exchange, and can be inspected, edited, disabled, or deleted, with prior versions retained until explicit deletion removes those too. Nothing is inferred from agent output, tool results, or imported material, and note-local direction stays in the note. The point: tentative thoughts ("maybe I do not want to manage people") must never harden into profile claims. Inference-based memory is the common industry pattern and we deliberately decline it.
