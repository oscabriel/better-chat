# V1 deliberately lacks cross-note search, attachments, and import

V1 supports text-only captures and recall scoped to a single note. There is no cross-note search (revisit only when explicit references demonstrably fail: a user wants to reference another note, cannot find it through recents, and loses the thread as a result), no file or image attachments and therefore no R2 bucket, and no import or read-only access to existing Better Chat conversations. Each absence keeps the ten-step experiment focused on the correction, undo, and stop interactions that define the product, and each can be added later without reversing an architectural decision.
